二、安装 JDK（Java开发环境）
================================================================

【下载地址】
官网：https://www.oracle.com/java/technologies/downloads/
推荐使用 JDK 17 或 JDK 21（长期支持版本）

或使用国内镜像（速度更快）：
华为镜像：https://repo.huaweicloud.com/java/jdk/

【安装步骤】
1. 下载对应操作系统的安装包（Windows选择 .exe 或 .msi 文件）
2. 双击安装包，按默认设置一路"下一步"即可
3. 记住安装路径（例如：C:\Program Files\Java\jdk-17）

【配置环境变量】
1. 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
2. 在"系统变量"中点击"新建"：
   变量名：JAVA_HOME
   变量值：C:\Program Files\Java\jdk-17（改成你的实际安装路径）
3. 找到"系统变量"中的 Path，双击打开，点击"新建"，添加：
   %JAVA_HOME%\bin
4. 点击"确定"保存所有设置

【验证安装】
1. 按 Win+R，输入 cmd，回车，打开命令行
2. 输入：java -version
3. 如果显示版本号（如 java version "17.0.x"），说明安装成功

三、安装 MySQL（数据库）
================================================================

【下载地址】
官网：https://dev.mysql.com/downloads/installer/
选择 "MySQL Installer for Windows" → 下载较大的那个安装包（mysql-installer-community）

推荐使用 MySQL 8.0 版本

【安装步骤】
1. 双击安装包运行
2. 选择安装类型："Developer Default"（开发者默认）或 "Server only"（仅服务器）
3. 点击 "Next" → "Execute" 开始安装
4. 配置 MySQL Server：
   - 选择 "Standalone MySQL Server"
   - 端口保持默认 3306
   - 设置 root 密码为：root（⚠️ 必须设为 root，否则需要修改项目配置）
   - Windows Service Name 保持默认 MySQL80
5. 一路 "Next" → "Execute" → "Finish"

【验证安装】
1. 按 Win+R，输入 cmd，回车
2. 输入：mysql -u root -proot
3. 如果进入 mysql> 提示符，说明安装成功
4. 输入 exit 退出

如果提示"mysql 不是内部命令"：
- 找到 MySQL 安装目录下的 bin 文件夹（通常是 C:\Program Files\MySQL\MySQL Server 8.0\bin）
- 将这个路径添加到系统环境变量 Path 中（方法同 JDK）

四、安装 Node.js（前端运行环境）
================================================================

【下载地址】
官网：https://nodejs.org/
下载 LTS（长期支持）版本，推荐 18.x 或 20.x

【安装步骤】
1. 双击安装包
2. 一路"Next"，全部使用默认设置
3. 安装完成

【验证安装】
1. 按 Win+R，输入 cmd，回车
2. 输入：node -v
   应显示版本号，如 v18.17.0
3. 输入：npm -v
   应显示版本号，如 9.6.7

【配置淘宝镜像（加速下载）】
在命令行输入：
npm config set registry https://registry.npmmirror.com

五、安装 Maven（Java项目构建工具）
================================================================

【下载地址】
官网：https://maven.apache.org/download.cgi
下载 "Binary zip archive"（apache-maven-3.9.x-bin.zip）

【安装步骤】
1. 将下载的 zip 文件解压到一个目录（例如：C:\maven\apache-maven-3.9.6）
   注意：路径中不要有中文和空格！

2. 配置环境变量：
   a. 新建系统变量：
      变量名：MAVEN_HOME
      变量值：C:\maven\apache-maven-3.9.6（改成你的实际路径）
   b. 编辑 Path 变量，新增：
      %MAVEN_HOME%\bin

3. 配置 Maven 镜像（加速下载依赖）：
   a. 打开 C:\maven\apache-maven-3.9.6\conf\settings.xml
   b. 找到 <mirrors> 标签，在里面添加：

   <mirror>
     <id>aliyunmaven</id>
     <mirrorOf>*</mirrorOf>
     <name>阿里云公共仓库</name>
     <url>https://maven.aliyun.com/repository/public</url>
   </mirror>

   c. 保存文件

【验证安装】
1. 重新打开命令行（之前的命令行需要关掉重开才能生效）
2. 输入：mvn -version
3. 显示版本信息说明安装成功

七、导入数据库
================================================================

数据库SQL文件位置：项目根目录/mall-system/sql/sql.sql

【方法一：使用命令行导入（推荐）】
1. 打开命令行（cmd）
2. 先登录 MySQL 创建数据库：
   mysql -u root -proot
3. 在 mysql> 提示符下输入：
   CREATE DATABASE book_trading_platform DEFAULT CHARACTER SET utf8mb4;
4. 输入 exit 退出 mysql
5. 导入 SQL 文件（注意修改路径中的项目位置）：
   mysql -u root -proot book_trading_platform < "你的项目路径\mall-system\sql\sql.sql"
   
   例如：
   mysql -u root -proot book_trading_platform < "D:\projects\mall-system\sql\sql.sql"

【方法二：使用 Navicat 等可视化工具导入】
1. 打开 Navicat（或其他 MySQL 可视化工具）
2. 连接到本地 MySQL（主机：localhost，端口：3306，用户名：root，密码：root）
3. 右键 → 新建数据库 → 数据库名输入：book_trading_platform → 字符集选 utf8mb4
4. 双击打开该数据库
5. 右键数据库 → 运行 SQL 文件 → 选择 mall-system/sql/sql.sql → 开始
6. 运行完成后刷新，应该能看到15张数据表

【验证导入】
1. 命令行登录 MySQL：mysql -u root -proot
2. 输入：USE book_trading_platform;
3. 输入：SHOW TABLES;
4. 应该显示15张表（admin, announcement, book, book_category, 
   book_collect, book_order, browsing_history, message, 
   order_evaluate, shipping_address, shop, shop_collect, 
   shopping_cart, slideshow, user）

⚠️ 重要：导入数据库后需要手动添加一个字段：
mysql -u root -proot -e "ALTER TABLE book_trading_platform.book_order ADD COLUMN order_evaluate_id INT DEFAULT NULL COMMENT '评价ID';"

八、用IDEA打开并配置后端项目
================================================================

【打开项目】
1. 启动 IntelliJ IDEA
2. 点击 "Open"（打开）
3. 找到项目目录下的 mall-system 文件夹
4. 选中 mall-system 文件夹，点击"确定"
5. 如果弹出"Trust Project?"对话框，点击"Trust Project"

【配置 JDK】
1. 菜单栏 → File → Project Structure（或按 Ctrl+Alt+Shift+S）
2. 左侧选择 "Project"
3. Project SDK：选择你安装的 JDK（如 JDK 17）
   如果列表中没有，点击"Add SDK" → "JDK" → 找到 JDK 安装目录
4. Project language level：选择对应版本（如 17）
5. 点击 "OK"

【配置 Maven】
1. 菜单栏 → File → Settings（或按 Ctrl+Alt+S）
2. 搜索 "Maven"
3. Maven home path：选择你的 Maven 安装目录
   例如：C:\maven\apache-maven-3.9.6
4. User settings file：勾选 Override，选择 Maven 目录下的 conf\settings.xml
5. 点击 "OK"

【等待依赖下载】
1. 打开项目后，IDEA 右下角会显示进度条，正在下载 Maven 依赖
2. 这个过程需要几分钟（取决于网速），请耐心等待
3. 如果下载很慢，检查 settings.xml 中是否配置了阿里云镜像

【修改数据库配置（如果需要）】
如果你的 MySQL 密码不是 root，需要修改配置文件：
1. 打开 mall-system/src/main/resources/application.yaml
2. 找到以下配置，修改为你的数据库信息：
   spring:
     datasource:
       url: jdbc:mysql://localhost:3306/book_trading_platform?...
       username: root       ← 改成你的用户名
       password: root       ← 改成你的密码

九、启动后端服务
================================================================

【方法一：IDEA中直接运行（推荐）】
1. 在 IDEA 左侧项目目录中找到：
   src → main → java → com → project → platform → ProjectManagement.java
2. 右键点击 ProjectManagement.java
3. 选择 "Run 'ProjectManagement.main()'"
4. 等待控制台输出：
   Started ProjectManagement in X.XX seconds
5. 看到这行日志说明后端启动成功，运行在端口 1000

【方法二：命令行启动】
1. 打开命令行，进入 mall-system 目录
2. 执行：mvn spring-boot:run
3. 等待看到 "Started ProjectManagement" 即启动成功

⚠️ 常见启动失败原因：
- 数据库未启动：确保 MySQL 服务正在运行
- 数据库未创建：确保已执行第七步导入数据库
- 端口被占用：1000 端口被其他程序占用，可修改 application.yaml 中的 port
- JDK版本不对：确保使用 JDK 17 或以上版本

十、启动前端项目
================================================================

前端代码位于：mall-system/web 目录

【安装前端依赖】
1. 打开命令行（cmd 或 PowerShell）
2. 进入前端目录：
   cd "你的项目路径\mall-system\web"
   
   例如：
   cd "D:\projects\mall-system\web"

3. 安装依赖（首次运行需要，以后不需要重复执行）：
   npm install
   
   这个过程需要几分钟，请等待完成。
   如果提示 WARN 是正常的，只要没有 ERROR 就行。
   如果报错，尝试：npm install --legacy-peer-deps

【启动前端开发服务器】
1. 在 web 目录下执行：
   npm run dev

2. 看到以下输出说明启动成功：
   VITE v5.x.x  ready in xxx ms
   ➜  Local:   http://localhost:5173/

3. 前端服务运行在 http://localhost:5173

⚠️ 注意：前端项目启动时，后端服务必须已经在运行！

十一、访问系统
================================================================

确保后端（端口1000）和前端（端口5173）都已启动后：

1. 打开浏览器（推荐 Chrome 或 Edge）
2. 访问地址：http://localhost:5173
3. 在登录页面输入测试账号（详见"测试账号密码.txt"）
4. 选择对应的角色登录

【各角色首页】
- 管理员登录后：进入后台管理系统（数据统计、各项管理功能）
- 买家登录后：进入前台首页（浏览书籍、购物、订单等）
- 卖家登录后：进入店铺管理（书籍管理、订单处理等）

十二、常见问题排查
================================================================

问题1：mysql 不是内部命令
解决：将 MySQL 安装目录下的 bin 文件夹路径添加到系统环境变量 Path 中

问题2：npm install 报错
解决：
  a. 先执行：npm config set registry https://registry.npmmirror.com
  b. 再执行：npm install --legacy-peer-deps
  c. 如果还报错，删除 node_modules 文件夹和 package-lock.json，重新 npm install

问题3：后端启动报数据库连接失败
解决：
  a. 确认 MySQL 服务已启动（在服务中查找 MySQL80）
  b. 确认数据库 book_trading_platform 已创建并导入了 sql.sql
  c. 确认 application.yaml 中的用户名密码与你的 MySQL 一致

问题4：前端页面打不开或白屏
解决：
  a. 确认后端服务已启动（访问 http://localhost:1000 不报"无法访问"）
  b. 确认前端 npm run dev 正在运行
  c. 清除浏览器缓存后刷新

问题5：IDEA 中找不到 JDK
解决：File → Project Structure → Project → Add SDK → 找到 JDK 安装目录

问题6：Maven 依赖下载很慢
解决：确认 settings.xml 中配置了阿里云镜像（见第五步）

问题7：端口 1000 被占用
解决：
  a. 命令行执行：netstat -ano | findstr :1000
  b. 记下占用端口的 PID
  c. 执行：taskkill /PID 那个PID /F
  d. 或者修改 application.yaml 中的 port 为其他端口（如 8080）

问题8：页面显示乱码或"????"
解决：
  a. 清除浏览器 LocalStorage（F12 → Application → Local Storage → 清除）
  b. 退出登录后重新登录
